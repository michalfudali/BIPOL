📐 Krok 1.1: Wstępne oszacowanie doskonałości aerodynamicznej \(K_{\max}\)
BIPOL I Wzór (8) • prof. C. Galiński, dr inż. T. Grabowski

Przed wyznaczeniem szczegółowej geometrii płatowca, maksymalną doskonałość aerodynamiczną układu nośnego szacuje się na podstawie założonego wydłużenia skrzydła, współczynnika sprawności aerodynamicznej Oswalda oraz przewidywanego oporu szkodliwego.

\[ K_{\max} = \frac{1}{2} \sqrt{\frac{\pi \cdot \Lambda \cdot e}{C_{x0 }} } \]
Wykaz i źródło zmiennych składowych:
  • \(\Lambda\) = {{ res.geometry.wing.AR }} [-] — założone wydłużenie skrzydła, dobrane z bazy statystycznej dla klasy samolotu
  • \(e\) = {{ params.oswald_e }} [-] — współczynnik sprawności Oswalda (dla skrzydła o zbieżności \(\eta = {{ res.geometry.wing.eta }}\))
  • \(C_{x0}\) = {{ res.aerodynamics.cx0_clean }} [-] — współczynnik oporu szkodliwego, oszacowany metodą powierzchni omywanej \(C_{fe} \cdot S_{wet}/S\)
Podstawienie liczbowe krok po kroku:
\[ K_{\max} = \frac{1}{2} \sqrt{\frac{\pi \cdot {{ res.geometry.wing.AR }} \cdot {{ params.oswald_e }} }{ {{ res.aerodynamics.cx0_clean }} }} = \frac{1}{2} \sqrt{\frac{ {{ (3.14159 * res.geometry.wing.AR * params.oswald_e)|round(3) }} }{ {{ res.aerodynamics.cx0_clean }} }} = \mathbf{ {{ res.aerodynamics.k_max }} } \]
✔️ Weryfikacja inżynierska: Uzyskana wartość \(K_{\max} = {{ res.aerodynamics.k_max }}\) mieści się w granicach statystycznych dla danej klasy konstrukcyjnej i stanowi bazę do równania zasięgu Bregueta.
⚙️ Krok 1.2: Ciąg niezbędny i moc niezbędna do lotu przelotowego (\(V_{cr}\))
BIPOL I Wzory (19)–(22) • Mechanika Lotu I

W poziomym locie ustalonym siła ciągu równoważy siłę oporu aerodynamicznego (\(T_{req} = Q = m_0 g / K\)). Na tej podstawie określa się wstępne zapotrzebowanie mocy na wysokości przelotowej \(H = {{ params.cruise_altitude_m }}\text{ m}\).

{% if params.engine_type == 'jet' %}
\[ T_{req,cr} = \frac{m_0 \cdot g}{K_{cr}}, \quad P_{req,cr} = T_{req,cr} \cdot V_{cr} \]
{% elif params.engine_type == 'none' %}
\[ w_{sink,cr} = \frac{V_{cr}}{K_{cr}} \quad (\text{lot szybowy bezsilnikowy}) \]
{% else %}
\[ T_{req,cr} = \frac{m_0 \cdot g}{K_{cr}}, \quad P_{req,cr} = \frac{T_{req,cr} \cdot V_{cr}}{\eta_p} = \frac{m_0 \cdot g \cdot V_{cr}}{K_{cr} \cdot \eta_p} \]
{% endif %}
Wykaz i źródło zmiennych składowych:
  • \(m_0\) = {{ res.mass.m0 }} kg — wstępna maksymalna masa startowa (MTOW) z bilansu masowego
  • \(g\) = 9.807 m/s² — przyspieszenie ziemskie standardowe
  • \(V_{cr}\) = {{ params.cruise_speed_kmh }} km/h = {{ (params.cruise_speed_kmh / 3.6)|round(1) }} m/s — prędkość przelotowa z założeń misji
  • \(K_{cr}\) = {{ res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max }} — doskonałość aerodynamiczna w punkcie przelotowym
    • {% if params.engine_type not in ['jet', 'none'] %}
  • \(\eta_p\) = {{ params.prop_efficiency_cruise if params.prop_efficiency_cruise else 0.80 }} — sprawność śmigła w fazie przelotu (założenie projektowe)
    • {% endif %}
Podstawienie liczbowe krok po kroku:
{% if params.engine_type == 'jet' %} \[ T_{req,cr} = \frac{ {{ res.mass.m0 }} \cdot 9.807}{ {{ res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max }} } = \mathbf{ {{ ((res.mass.m0 * 9.80665 / (res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max)) / 1000)|round(2) }} \text{ kN} } \] \[ P_{req,cr} = {{ ((res.mass.m0 * 9.80665 / (res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max)) / 1000)|round(2) }}\text{ kN} \cdot {{ (params.cruise_speed_kmh / 3.6)|round(1) }}\text{ m/s} = \mathbf{ {{ ((res.mass.m0 * 9.80665 / (res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max) * (params.cruise_speed_kmh / 3.6)) / 1000)|round(1) }} \text{ kW} } \] {% elif params.engine_type == 'none' %} \[ w_{sink,cr} = \frac{ {{ (params.cruise_speed_kmh / 3.6)|round(1) }}\text{ m/s}}{ {{ res.aerodynamics.k_max }} } = \mathbf{ {{ ((params.cruise_speed_kmh / 3.6) / res.aerodynamics.k_max)|round(2) }} \text{ m/s} } \] {% else %} \[ T_{req,cr} = \frac{ {{ res.mass.m0 }} \cdot 9.807}{ {{ res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max }} } = \mathbf{ {{ ((res.mass.m0 * 9.80665 / (res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max)) / 1000)|round(2) }} \text{ kN} } \] \[ P_{req,cr} = \frac{ {{ ((res.mass.m0 * 9.80665 / (res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max)))|round(1) }}\text{ N} \cdot {{ (params.cruise_speed_kmh / 3.6)|round(1) }}\text{ m/s}}{ {{ params.prop_efficiency_cruise if params.prop_efficiency_cruise else 0.80 }} \cdot 1000} = \mathbf{ {{ ((res.mass.m0 * 9.80665 / (res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max) * (params.cruise_speed_kmh / 3.6)) / ((params.prop_efficiency_cruise if params.prop_efficiency_cruise else 0.80) * 1000))|round(1) }} \text{ kW} } \] {% endif %}

⛽ Krok 2.1: Ułamek paliwa misji i równanie zasięgu Bregueta
BIPOL I Wzory (19)–(29) • Roskam Part I • Raymer eq. (3.11)

Profil misji dzieli się na etapy: rozruch, start, wznoszenie, przelot trasy \(R\), zniżanie, oczekiwanie i lądowanie. Ułamek zużycia paliwa w przelocie wyznacza się z odwróconego wzoru Bregueta:

{% if params.engine_type == 'jet' %}
\[ \left(\frac{W_4}{W_3}\right)_{cruise} = \exp\left(-\frac{R \cdot c_j \cdot g}{V_{cr} \cdot K_{cr}}\right), \quad M_{ff} = \prod_{i=1}^n \left(\frac{W_i}{W_{i-1}}\right), \quad \frac{m_f}{m_0} = 1.06 \cdot (1 - M_{ff}) \]
{% elif params.engine_type == 'none' %}
\[ \frac{m_f}{m_0} = 0 \quad (\text{szybowiec czysty - brak paliwa pokładowego}) \]
{% else %}
\[ \left(\frac{W_4}{W_3}\right)_{cruise} = \exp\left(-\frac{R \cdot c_p \cdot g}{\eta_p \cdot K_{cr} \cdot 3.6 \cdot 10^6}\right), \quad M_{ff} = \prod_{i=1}^7 \left(\frac{W_i}{W_{i-1}}\right), \quad \frac{m_f}{m_0} = 1.06 \cdot (1 - M_{ff}) \]
{% endif %}
Wykaz i źródło zmiennych składowych:
  • \(R\) = {{ params.range_km }} km — założony zasięg obliczeniowy misji
  • \(c_p\) = {{ params.sfc_cruise_g_kwh if params.sfc_cruise_g_kwh else 270 }} g/(kW•h) — jednostkowe zużycie paliwa wybranego silnika
  • \(K_{cr}\) = {{ res.mass.ld_cruise_used if res.mass.ld_cruise_used else res.aerodynamics.k_max }} — doskonałość aerodynamiczna w fazie przelotu
  • \(M_{ff}\) = {{ res.mass.fuel_fractions_detail.total_mff }} — iloczyn ułamków masowych wszystkich faz misji (Mission Fuel Fraction)
  • Mnożnik 1.06 — uwzględnienie 6% rezerwy paliwa niewykorzystywalnego wg CS-23/25
Podstawienie liczbowe krok po kroku:
\[ \left(\frac{W_4}{W_3}\right)_{cruise} = {{ res.mass.fuel_fractions_detail.cruise }}, \quad M_{ff} = {{ res.mass.fuel_fractions_detail.total_mff }} \] \[ \frac{m_f}{m_0} = 1.06 \cdot (1 - {{ res.mass.fuel_fractions_detail.total_mff }}) = \mathbf{ {{ res.mass.fuel_fraction }} } \implies m_f = \mathbf{ {{ res.mass.m_fuel }} \text{ kg} } \]
✔️ Weryfikacja: Zapas paliwa \(m_f = {{ res.mass.m_fuel }}\text{ kg}\) zapewnia realizację misji o zasięgu {{ params.range_km }} km z uwzględnieniem 45-minutowej rezerwy holdingowej (CS-23.903).
⚖️ Krok 2.2: Równanie wymiarujące maksymalną masę startową (MTOW)
BIPOL I • prof. C. Galiński • Roskam / Torenbeek

Masa startowa \(m_0\) jest sumą masy ładunku, załogi, paliwa i masy pustej. Z uwagi na nieliniową zależność masy pustej \(m_e(m_0)\), równanie rozwiązuje się iteracyjnie:

\[ m_0 = \frac{m_{pl} + m_{crew}}{1 - \frac{m_f}{m_0} - \frac{m_e}{m_0}(m_0)}, \quad \text{gdzie } \frac{m_e}{m_0} = A \cdot m_0^C \cdot K_{var} \]
Wykaz i źródło zmiennych składowych:
  • \(m_{pl}\) = {{ res.mass.m_payload }} kg — masa płatna (pasażerowie + bagaż lub sensory UAV) z założeń taktyczno-technicznych
  • \(m_{crew}\) = {{ res.mass.m_crew }} kg — masa załogi ({{ params.n_crew }} os. × 90 kg z bagażem podręcznym)
  • \(m_f/m_0\) = {{ res.mass.fuel_fraction }} — udział masowy paliwa całkowitego z Kroku 2.1
  • \(m_e/m_0\) = {{ res.mass.empty_fraction }} — udział masy pustej wyznaczony ze statystyk Roskama
Podstawienie liczbowe krok po kroku:
\[ m_0 = \frac{ {{ res.mass.m_payload }} + {{ res.mass.m_crew }} }{1 - {{ res.mass.fuel_fraction }} - {{ res.mass.empty_fraction }} } = \frac{ {{ (res.mass.m_payload + res.mass.m_crew)|round(1) }} }{ {{ (1.0 - res.mass.fuel_fraction - res.mass.empty_fraction)|round(4) }} } = \mathbf{ {{ res.mass.m0 }} \text{ kg} } \] \[ m_e = {{ res.mass.empty_fraction }} \cdot {{ res.mass.m0 }} = \mathbf{ {{ res.mass.m_empty }} \text{ kg} } \quad ({{ (res.mass.empty_fraction * 100)|round(1) }}\% \text{ MTOW}) \]
✔️ Weryfikacja: Zbieżność iteracji osiągnięto z tolerancją < 0.1 kg. Udział masy pustej {{ (res.mass.empty_fraction * 100)|round(1) }}% odpowiada standardom nowoczesnych konstrukcji lotniczych.

📐 Krok 3.1: Wymiary skrzydła (Obrys: {{ res.geometry.wing.planform_name_pl if res.geometry.wing.planform_name_pl else 'Trapezowy' }}) i Średnia Cięciwa Aerodynamiczna (ŚDA)
prof. J. Danilecki "Konstruowanie samolotów" rozdz. 3 • Metoda Schrenka

Na podstawie wyznaczonej powierzchni nośnej \(S = {{ res.geometry.wing.S }}\text{ m}^2\), założonego wydłużenia \(\Lambda = {{ res.geometry.wing.AR }}\) oraz zbieżności \(\eta = {{ res.geometry.wing.eta }}\), wyznacza się rozpiętość, cięciwy oraz parametry ŚDA:

\[ b = \sqrt{S \cdot \Lambda}, \quad c_r = \frac{2 \cdot S}{b \cdot (1 + \eta)}, \quad c_t = \eta \cdot c_r \] \[ b_A = \text{ŚDA} = \frac{2}{3} \cdot c_r \cdot \frac{1 + \eta + \eta^2}{1 + \eta}, \quad y_{\text{ŚDA}} = \frac{b}{6} \cdot \frac{1 + 2\eta}{1 + \eta} \]
Wykaz i źródło zmiennych składowych:
  • \(S\) = {{ res.geometry.wing.S }} m² — powierzchnia nośna skrzydła z punktu projektowego Matching Chart
  • \(\Lambda\) = {{ res.geometry.wing.AR }} — wydłużenie skrzydła z założeń koncepcyjnych
  • \(\eta = c_t/c_r\) = {{ res.geometry.wing.eta }} — zbieżność trapezowa (optymalna pod kątem eliptycznego rozkładu siły nośnej wg Schrenka)
Podstawienie liczbowe krok po kroku:
