Charakterystyki aerodynamiczne samolotu

{% set cc=p_data.cg_characteristics %}{% set cm=cc.cm_model %}

Charakterystyki samolotu wyznaczono metodą Tabeli 2.2 Paturskiego. Do płata dodano opór szkodliwy zespołów, siłę nośną i opór usterzenia poziomego potrzebne do równowagi oraz poprawkę interferencji. Tabelę sporządzono dla średniego położenia środka ciężkości \(\bar x={{ ((cm.x_fwd_pct+cm.x_aft_pct)/2)|texnum(1) }}\%\) ŚCA. Funkcja energetyczna \(E=C_z^3/C_x^2\) osiąga maksimum przy najmniejszym opadaniu.

Współczynnik momentu \(C_m(\alpha)\) przedstawiono w przybliżeniu liniowym przy ustalonym sterze wysokości. Ster ustawiono tak, aby samolot był wyważony w przelocie (\(C_z={{ cm.cz_ref|texnum(3) }}\)) przy średnim położeniu środka ciężkości. Punkt neutralny przyjęto z analizy wyważenia: \(\bar x_N={{ cm.x_n_pct|texnum(1) }}\%\) ŚCA. Pominięto moment od ciągu i oporu oraz nieliniowość w pobliżu przeciągnięcia.

\[C_m=C_{m0}+(\bar x-\bar x_N)\,C_z,\qquad C_{m0}=(\bar x_N-\bar x_{śr})\,C_{z,przel}={{ cm.cm0|texnum(4) }}.\]

Dla przedniego położenia środka ciężkości (\({{ cm.x_fwd_pct|texnum(1) }}\%\) ŚCA) \(\mathrm dC_m/\mathrm dC_z={{ cm.dcm_dcz_fwd|texnum(3) }}\){% if cm.cz_trim_fwd is not none %}, a samolot z ustalonym sterem równoważy się przy \(C_z={{ cm.cz_trim_fwd|texnum(3) }}\){% endif %}. Dla tylnego (\({{ cm.x_aft_pct|texnum(1) }}\%\) ŚCA) \(\mathrm dC_m/\mathrm dC_z={{ cm.dcm_dcz_aft|texnum(3) }}\){% if cm.cz_trim_aft is not none %} i \(C_z={{ cm.cz_trim_aft|texnum(3) }}\){% endif %}.
