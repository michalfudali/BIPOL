Wstępna ocena aerodynamiczna

Powierzchnię omywaną oszacowano z geometrii głównych zespołów. Otrzymano \(S_{wet} = {{ p_data.s_wet_m2|texnum(2) }}\) m² oraz \(S_{wet}/S = {{ p_data.swet_over_s|texnum(2) }}\). Doskonałość obliczono z tej samej biegunowej, która służy do wyznaczania osiągów:

\[C_x=C_{x0}+kC_z^2,\qquad K_{\max}=\frac{1}{2\sqrt{C_{x0}k}}={{ res.aerodynamics.k_max|texnum(1) }}.\]

Przyjęto \(C_{x0}={{ res.aerodynamics.cx0_clean|texnum(4) }}\) i \(k={{ res.aerodynamics.k_clean|texnum(5) }}\). Współczynnik indukowany uwzględnia efektywne wydłużenie i kształt obrysu skrzydła. {% if doc.powered %}Dla prędkości przelotowej oszacowanie daje {% if params.engine_type == 'jet' %}ciąg niezbędny {{ p_data.t_req_est_kn|reportnum(2) }} kN{% else %}moc niezbędną {{ p_data.p_req_est_kw|reportnum(1) }} kW{% endif %}.{% endif %}
